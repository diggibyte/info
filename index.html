Employee Upskilling Program

8 weeks to build with agentic AI, not just talk about it.

Every team here already knows how to build reliable systems: that is the job. What is changing is the tooling. Agentic AI is becoming a normal part of how that work gets done, not an experiment on the side. This program exists so that shift happens deliberately, with real skill behind it, instead of piecemeal and reactive.

The goal is not to make everyone an AI researcher. It is to make sure that when a customer asks if something can be faster, cheaper, or more reliable, the answer is yes, because the team building it knows how to put agents to work on real data, real pipelines, and real decisions, safely and with the right guardrails in place.

A hands-on program for Data Engineering, AI/ML, BI, and Platform teams. Every week ends with something working: not a slide, an artifact you actually built.

The Weekly Journey

Core capability first, role depth next, production governance third, and final proof of value last.

Phase 1 · Weeks 1–3
Core FoundationWeeks 1–3

These three weeks establish the common language and working patterns across the program: AI-native work habits, GenAI foundations, and the first production-ready agent design patterns.

Week 1: AI-Native Ways of Working — prompting, context engineering, secure coding practices, and personal workflow acceleration.

Week 2: GenAI & RAG Foundations — LLM and GenAI basics, embeddings, retrieval-augmented generation, structured outputs, and model selection.

Week 3: Agent Architecture & Tooling — agent design patterns, tool calling, Model Context Protocol (MCP), persistent memory, and human-in-the-loop controls.

Outcome: a shared baseline across every team with real working artifacts.
Phase 2 · Weeks 4–5
Role SpecializationWeeks 4–5

Teams split into role-specific tracks and build a working agent tailored to their domain using the core foundations.

Week 4: Track Deep Dive — domain-specific agent architectures, MCP tool building, and semantic/data modeling for Data, AI, BI, or Platform engineering.

Week 5: Role Agent Implementation — build and test a functional, role-appropriate agent built for real operational value.

Outcome: a working, role-specific agent built for real operational value.
Phase 3 · Weeks 6–7
Production & Real-World ApplicationWeeks 6–7

This is where the work becomes trustworthy and useful beyond a prototype.

Week 6: Production Agent Engineering — evaluation, guardrails, Unity Catalog access, MLflow tracing, monitoring, and cost/latency control.

Week 7: Customer / Team Use Case Sprint — apply the work to a real problem with stakeholder feedback and iteration.

Outcome: a governed, evaluated agent and a validated real-world use case.
Phase 4 · Week 8
Evaluation & ShowcaseWeek 8

This final phase is not a scorecard — it is a live demonstration of impact, judgment, and reuse.

Live System Demonstration: Show the agent running end-to-end with live data and tools (no static slides or screenshots).

Impact Defense & Packaging: Walk through the 6 impact dimensions, defend design choices, explain failure fallbacks, and publish reusable team assets.

Outcome: real evidence of business value, delivery improvement, and reusable impact.

Weeks 4–5 · Role Tracks

Same two weeks, different destination. Pick the track that matches your role.

Data Engineers
→ Agentic Data Engineers

FOCUS AREAS

  • MCP / tool development
  • RAG data pipelines
  • Structured + unstructured ingestion
  • Metadata & context engineering
  • Lakeflow, Delta & Unity Catalog
  • Automated data-quality agents
Assignment: an Autonomous Data Pipeline Agent that detects an issue, diagnoses it, checks lineage/quality, and recommends or safely executes remediation.
Data Scientists
→ Agentic AI Engineers

FOCUS AREAS

  • Advanced RAG, embeddings & reranking
  • Tool calling & memory
  • Agent orchestration, multi-agent patterns
  • Model selection
  • Evaluation & hallucination testing
  • Guardrails & MLflow
Assignment: a multi-agent business analyst: planner, researcher/data agent, reasoning/analysis agent, and validation agent.
BI Engineers
→ AI/BI Engineers

FOCUS AREAS

  • Semantic modeling & trusted metrics
  • Genie / AI-BI
  • NL → SQL validation
  • Conversational analytics
  • Proactive insight generation
  • Action-oriented analytical agents
Assignment: instead of another dashboard: "Why did gross margin decline?" The agent investigates, identifies drivers, explains, and recommends actions.
Platform Engineers
→ Agentic Platform Engineers

FOCUS AREAS

  • Model serving & AI Gateway
  • MCP infrastructure
  • Identity & authorization
  • Unity Catalog governance & secrets
  • CI/CD, tracing & observability
  • Model routing, cost management, AgentOps
Assignment: a reusable Agent Platform Blueprint that other Diggibyte teams can deploy against.

Demonstrating Your Impact

Week 8 is not a scored exam. You show real, evidence-based impact across six dimensions, reviewed in a live demo.

DimensionWhat you must show
Customer value deliveredA clear before and after picture: what changed for a customer or internal stakeholder because of the agent or tool you built, described in plain terms a non-technical reviewer can understand.
Delivery improvementEvidence that your work reduced production issues: fewer bugs pushed, bugs caught before release, or a PM/reviewer sign-off confirming the improvement in delivery quality.
AI awareness and adoptionProof that you applied AI-native practices in your daily work, plus any contribution to spreading that awareness: a blog post written, an internal session or seminar delivered, or an external talk given.
Governance contributionDemonstrated understanding of cost and token usage: you can explain how you measured token consumption and what specific technique you used to reduce it (for example prompt trimming, caching, smaller model routing, or batching).
Knowledge sharingWhether your work was documented clearly enough that another team member could reuse it without asking you questions.
